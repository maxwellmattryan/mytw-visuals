## Sample image

`images/sample.png` is procedurally generated. To regenerate it, run this from the repository root (output bytes may differ between `ffmpeg` versions):

```sh
ffmpeg -y -f lavfi -i "color=black:s=1080x1080,format=gbrp,geq=r='128+127*sin(X/90+2*sin(Y/140))':g='128+127*sin(Y/70+2*sin(X/110))':b='128+127*sin((X+Y)/120)'" -frames:v 1 apps/sketchbook/assets/images/sample.png
```
