# Builder addendum

- **UI proofs: keep scratch files in the job dir and use the installed Chrome.** Daemon sessions can't write to `/tmp`, so write proof scripts and browser profiles under `.forge/jobs/<id>/` (scripts in `proof/`, images in `screenshots/`) from the start. Try the browser tools first. Call `browser_find` again before each click, since refs go stale, and wait more than 5 s after starting a recording. If you need a script, launch Google Chrome with playwright-core's `chromium.launch({ channel: 'chrome', headless: true })`. Don't search the worktree for a browser, since none of the workspaces ships one. Use a fresh profile dir per run, delete it at the end and set a timeout on each step, so a profile lock doesn't start a kill-and-retry loop. Jobs 7, 8, 9 and 10 lost about 34 builder turns to these issues. (added 2026-11-08 · experiment: builder-browser-proof · review-by: 2026-12-06)
