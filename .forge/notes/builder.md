# Builder addendum

- **UI proofs: use the forge-browser tools, and a CDP script in the job dir only for steps they can't do.** Take screenshots, click, press keys and run `eval` with the `browser_*` tools against `forge run <id> dev --background`. Take a fresh snapshot before you reuse a ref after a click, and copy files for `browser_file_upload` under `.forge/jobs/<id>/` first. playwright-core and puppeteer aren't installed, and adding either is a dependency escalation, so don't look for them. When a step needs a script (file downloads, frame grabs from a WebGL canvas), start `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --remote-debugging-port=<port> --user-data-dir=.forge/jobs/<id>/proof/profile` and drive it over CDP with Node 22's built-in `WebSocket`. Keep the script, profile and downloads under `.forge/jobs/<id>/proof/`, never `/tmp`, and write the script with the Write tool rather than a heredoc. Call `Browser.setDownloadBehavior` with that `downloadPath` on every connection, and wait for the file to appear before closing the socket, since a download that outlives the connection lands in `~/Downloads`. Delete the profile when you're done. Jobs 14, 17, 18 and 19 each rebuilt this harness in `/tmp`, about 40 builder turns. (added 2026-11-09 · experiment: builder-cdp-proof · review-by: 2026-12-07)
